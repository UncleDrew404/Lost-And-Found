
### 2. Password Double-Hash Bug (INVESTIGATED — NOT A BUG)

`HasAttributes::castAttributeAsHashedString()` (Laravel 12 source, line 1477) calls `Hash::isHashed($value)` before re-hashing. Since `bcrypt()` and `Hash::make()` both produce values that pass `password_get_info()` → `isHashed()`, the `hashed` cast correctly skips already-hashed input. No fix needed.

### 3. Public Item Browsing ✅ DONE

### 4. Register Should Return a Token ✅ DONE

### 5. Add `GET /api/v1/auth/user` Endpoint ✅ DONE
